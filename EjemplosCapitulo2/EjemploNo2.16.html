Características de Python

  • Sintaxis legible: Utiliza indentación en lugar de llaves para separar bloques de código, que facilita la lectura.
  • Lenguaje interpretado: El código se ejecuta directamente línea por línea sin necesidad de compilarlo antes.
  • Tipado dinámico: No necesita declarar el tipo de datos de una variable, el propio interprete de python detecta e infiere el tipo.
  • Multiplataforma: Multiplataforma: Funciona sin problemas en diferentes sistemas operativos como Windows, macOS y Linux.
  • Multiparadigma: Soporta varios estilos de programación, como la programación orientada a objeto o la programación funcional.
