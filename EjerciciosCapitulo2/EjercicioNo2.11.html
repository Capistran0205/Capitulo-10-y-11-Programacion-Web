Ejercicio 2.11

Indique cuál de los siguientes enunciados es verdadero y cuál es falso. Si es falso, explique por qué.

  1. Un documento de HTML5 válido no puede contener letras mayúsculas en nombres de elementos.
  2. Los documentos de HTML5 pueden tener la extensión de archivo .htm
  3. &less; es la referencia a entidad de carácter para el carácter menor que (<)< /li>
  4. En un documento de HTML5 válido, li puede anidarse dentro de equitetas ol o ul

Respuestas

  1. Falso. Un documento HTML5 válido sí puede contener letras mayúsculas en los nombres de los elementos
  2. Verdadero.
  3. Falso. la referencia de entidad para el signo menor que (<) en HTML es (& seguido de lt ) → <
  4. Verdadero.
