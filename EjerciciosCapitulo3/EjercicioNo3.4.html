Ejercicio 3.4

Completa las siguientes oraciones

  1. Los navegadores que despliegan el tipo input color como campo de texto requieren que el usuario introduzca el nombre de un color.
    2. Falso. Los navegadores que despliegan la entrada input de color como campo texto (cuando no soportan el selector de color) requieren que el usuario introduzca un valor hexadecimal y no por nombre de color.
  2. Cuando un usuario introduce datos en un formulario y luego lo envía (por lo general, al hacer clic en el botón Enviar), el navegador verifica de inmediato que los datos sean correctos.
    3. Verdadero.
  3. HTML5 puede validar si la dirección de correo electrónico introducida por el usuario existe en realidad.
    4. Falso. En HTML5 solo puede validar que el formato de la dirección de correo sea correcto, pero no puede verificar si esa dirección realmente existe o se encuentrá activa.
  4. Puede agregar required a cualquiera de los tipos input.
    5. Falso. No se puede agregar el atributo required a cualquier tipo de input como reset,button o image.
  5. Puede habilitar autocomplete sólo para ciertos elementos input.
    6. Verdadero.
  6. El elemento time nos permite identificar una fecha, hora o ambas.
    7. Verdadero.
  7. El elemento caption proporciona una leyenda para la imagen en un elemento figure.
    8. Falso. El elemento que proporciona la leyenda de una imagen dentro de figure es figcaption, no caption
  8. El elemento details muestra una flecha que apunta a la derecha enseguida de un resumen o leyenda cuando el documento se despliega en un navegador. AL hacer clic en la flecha, esta apunta hacia abajo y revela el contenido del elemento summary.
    9. Falso. Está al reves, cuando se hace clic en la flecha (la cual apunta hacia abajo) se revela el contenido del elemento details, no del elemento summary. El summary es justanmente el texto/leyenda visible e interactuable mediante un clic.
  9. El elemento footer describe el contenido que por lo general aparece en la parte inferior del contenido o del elemento section.
    10. Verdadero.
  10. El elemento highlight nos permite resaltar el texto.
    11. Falso. No existe un elemento nombrado como highlight en HTML5. El elemento que permite resaltar texto es mark.
